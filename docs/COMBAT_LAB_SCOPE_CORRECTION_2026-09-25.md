# Combat Lab — Scope Correction / Refoundation Pressure

**Date:** 2026-09-25  
**Status:** Owner-confirmed project scope correction  
**Trigger:** first positive R3 Owner specimen exposed a risk of overfitting the project around sword contact

## Core correction

Combat Lab is not a sword-combat project and is not limited to "hitting".

Its purpose is to discover useful embodied combat possibility spaces.

This includes systems where the important variable may be:

- body size / envelope / proportions;
- mass and movement;
- reach;
- weapon geometry;
- shields and occupied space;
- spears / polearms;
- axes;
- bows / projectiles;
- magic;
- terrain;
- multiple participants;
- mixed ranged/melee/magic relationships;
- persistence of state before, during and after exchange;
- other combat phenomena not yet named.

The list is illustrative, not a roadmap.

## R3 consequence

R3 produced an early positive Owner signal and is worth preserving.

It does **not** earn ownership of the roadmap.

Do not infer:

- "physical swords are the combat direction";
- "R4 must be next";
- "the lab should now deepen melee physics";
- "all future experiments should reuse the R3 controller/contact law".

R3 may become:

- a donor;
- one branch of a later comparison;
- a useful material-relation principle generalized beyond swords;
- or a dead end outside its current toy.

All remain open.

## Refoundation option

A substantial restart of the active implementation is explicitly acceptable.

A restart should preserve evidence but may discard implementation structure.

Preserve:

- exact SHAs;
- Owner observations;
- failed hypotheses and falsifiers;
- qualified causal kernels;
- methodological lessons;
- useful donor relations.

Feel free to replace:

- branch topology;
- current specimen architecture;
- controller conventions;
- naming;
- experiment sequencing;
- code substrate;
- assumptions inherited from the current melee-heavy history.

## Decision pressure before next build

Before choosing the next implementation lane, ask:

> **What important part of the combat possibility space are we currently blind to because our history has made melee/contact too cognitively available?**

Then compare the value of:

- continuing R3;
- opening a materially different combat family;
- testing body-scale effects;
- testing mixed modalities;
- or refounding the lab substrate before any new specimen.

Do not choose from this list by elegance. Choose from evidence and Owner intent.
