## 2. What Combat Lab is for

Combat Lab is a **permissive, self-directed research environment** for discovering embodied combat / movement / multi-actor possibility for Feniks.

It is not a polished game mode and not merely a crowd simulator.

The Owner wants to be able to:

- intervene live;
- set exact and extreme values;
- change independent raw dimensions;
- intentionally break the system;
- observe causal consequences;
- move quickly between hypotheses;
- understand *why* something happened rather than stare at generic debug counters.

Do not make the Lab paternalistic.

Do not solve extremes through:

- hidden clamping;
- hidden despawn;
- ghosting;
- silent substitution of safer values;
- automatic suppression of pathological regimes.

Ordinary-valid experiments and intentional-break experiments should be explicit and separate.

Owner-observed behavior remains authoritative for product/experience claims.
Machine PASS is mechanistic evidence, not a substitute for Owner qualification.
