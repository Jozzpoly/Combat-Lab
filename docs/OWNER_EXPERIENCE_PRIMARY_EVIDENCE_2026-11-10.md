## Why a different AI provider should start here

1. Combat Lab is for the Owner's **physical, creative agency**: alter bodies and materials, run real situations, push extreme values, watch consequences, deliberately break the world, and rebuild. Do not substitute an expert-only microscope or numerical traffic demo for this workflow.
2. **Safety rails must be legible.** If a physical limit is needed for numerical stability, report it explicitly and support bounded stress/failure experiments where feasible. Do not silently rewrite the Owner's intended value.
3. **A green machine gate is not an Owner-success claim.** This historical contradiction is particularly well documented by the 6 Oct recording.
4. When rebuilding experiments, verify the actual source and runtime; a written report is not equivalent to raw video and should not be embellished into confident gameplay claims.
5. Use the [forensic branch inventory](BRANCH_INVENTORY_2026-11-10.json) and the [archive-only cold recovery test](../tools/rehearse-archive-recovery.mjs) to recover original commits without reviving all abandoned branches. An archive graph is not a playable project.
