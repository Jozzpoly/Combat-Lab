# Combat Lab — Z1: Contact-only relations

**Separate, replaceable research alternative. Unqualified by Owner; not a merge target or public build.**

A deliberate counterfactual to X0/Y1, which gained significant apparent action via an approximate adhesive contact-hold. This experiment **removes that entire acquisition mechanism**, uses the existing Rapier solver and finite movement/limb forces, and arranges in one freely editable continuous world physical opportunities to move three different classes of matter: a free load, an anchored hinge and a rail-constrained slider. The UI retains editable organs, mass, obstacles and portable starting state, but right-click cannot attach material and any authored hold force is inert in this variant.

The field contains five bodies, five freely movable objects, one *passive* real hinge and one *passive* slider; no externally moving world drives, roaming/pathfinding or scripted puzzle completion. Manual actions always count as **researcher commands**, not autonomous NPC agency. Initial positions are deliberately research-authored to test possible contacts. CI compares movement with identical idle and zero-drive conditions and checks genuine solver impulses. This is intentionally **not** a proof that several activities are legible/fun in spontaneous play.

Stop rule: if contact-only actions cannot convincingly modify multiple types of material, or show only configured fixtures, acknowledge the limited 2D traction-proxy representation. Do not reintroduce adhesive hold under another name to force a passing score.
